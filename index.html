A streaming agent you can actually trust

I designed and built the streaming agent interface for a RAG-grounded analytics product. The goal: make an LLM's work visible, so analysts can see why an answer is right before they act on it.

  • Live thinking timeline. Typed SSE events drive each stage — interpretation, grounding, compute, verify — as it happens.
  • Auditable answers. Schema matches with relevance scores, governed-metric badges and one-click SQL make every result traceable.
  • One result, many views. Bar, pie, horizontal bar and table renderings side-by-side, with pin, analyze and export to PPT.
  • Ask → chart. A natural-language chart builder that drops straight into a saveable dashboard.

Dashboards that stay fast with lots of data

Multi-page, drag-and-drop dashboards built from agent-generated charts — designed to stay readable and responsive as the number of charts and rows grows.

  • Composable layouts. Draggable, resizable chart cards across pages, with combine, beautify, PNG export and present mode.
  • Rich visual vocabulary. KPI tiles, dual-axis combo charts, reference lines, ranked bars and labelled pies.
  • Drill-down per chart. Details, analysis and SQL on every card, plus per-chart palettes and type switching.
  • Server state done right. TanStack Query for caching, synchronisation and snappy refetches.
